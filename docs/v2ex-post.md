# [macOS] CoolRun：一个从金价监控慢慢长出来的菜单栏工具箱

作为用了 macOS 一年左右的新手，在使用过程中，我也遇到过一些突然觉得苹果系统不太方便的地方。后来发现，macOS 上很多自己的小需求，其实可以自己写软件解决。于是我借助 AI，一边学习、一边开发了 CoolRun：自己有什么需求，就继续往里面做什么功能。

刚开始它其实只是一个放在菜单栏里、用来监控金价波动的小工具。后来我想看 Mac 的运行状态，又不想一直打开活动监视器；想看日历、倒数日和农历，又不想在几个 App 之间来回切；使用 Codex 和 Claude Code 时，也想随手知道额度还剩多少……就这样，它一点点变成了现在这个有些“杂”、但都是我自己实际会用到的菜单栏工具箱。

![CoolRun 动态演示](https://raw.githubusercontent.com/kuaoaoaoao/CoolRun/main/docs/images/CoolRunShowDemo.gif)

## CoolRun 是什么

CoolRun 是一个原生 macOS 菜单栏应用，默认只待在菜单栏里，不占 Dock。左键点图标会打开一个悬浮面板，面板也可以用图钉固定；右键则可以直接打开“今天”、添加倒数日、记录黄金交易、刷新数据或进入设置。

菜单栏文字可以按自己的需求显示金价、日期、CPU、内存、网速、英语内容、最近倒数日或 Codex / Claude 额度，也支持同时显示两项，或者定时轮播。我做成菜单栏工具的原因很简单：这些信息都属于“想随手看一眼，但不值得专门打开一个大窗口”的东西。

![系统监控悬浮面板](https://raw.githubusercontent.com/kuaoaoaoao/CoolRun/main/docs/images/menu-popover-monitor.png)

## 目前做了哪些功能

### 1. 系统监控和 Mac 诊断

系统监控可以查看 CPU、内存、储存、电池、网络、温度、运行时间和进程占用，也会在本机保留最近 7 天的趋势，用来判断偶尔的卡顿到底是瞬时波动，还是持续异常。

这次 v4.0.0 我又加入了 Mac 诊断，主要解决几个我自己遇到过、但对新手来说不太好排查的问题：

- 为什么合盖后没有正常休眠，或者待机掉电很快；
- 网络到底卡在网卡、路由、DNS、外网还是 HTTPS；
- `System Data` 为什么越来越大，空间主要被哪些目录占用；
- App 已经卸载了，还留下了哪些高置信度残留文件。

诊断都需要手动触发，不会一直在后台扫描。储存分析是只读的；残留清理会再次确认，而且只移入废纸篓，不会直接永久删除。

### 2. 金价、走势和个人持仓

这是 CoolRun 最早的功能。除了在菜单栏显示积存金价格，现在还会记录历史走势，提供折线图、K 线、RSI、MACD、均线、波动率、支撑位和压力位等信息。

因为我自己也不是金融专业，所以我不希望界面只扔出一堆指标，而是尽量把它们翻译成“观望为主”“不要追高”“可以小额分批观察”这类新手能看懂的话。输入持有克数和买入均价后，还能计算成本、现值和浮盈浮亏，给出分批补仓、继续持有或部分止盈的参考。

![金价分析和新手解释](https://raw.githubusercontent.com/kuaoaoaoao/CoolRun/main/docs/images/gold-analyze2.png)

> 金价分析只是信息展示和个人记录，不构成投资建议，最终还是要自己判断风险。

### 3. 日历、倒数日、备忘录和剪切板

日历支持公历、农历、节假日和调休标记，也可以记录生日，以及一次性或每年重复的倒数日。倒数日、生日、英语打卡和持续的系统异常共用一套本地提醒，并支持提前提醒、免打扰时段和稍后提醒。

![公历、农历与节假日日历](https://raw.githubusercontent.com/kuaoaoaoao/CoolRun/main/docs/images/calendar.png)

备忘录支持分组、搜索和固定；剪切板会记录 CoolRun 启动后新复制的纯文本，支持搜索、固定、重新复制、暂停和清空，最多保留 200 条。这两部分内容都只保存在本机。

![分组备忘录](https://raw.githubusercontent.com/kuaoaoaoao/CoolRun/main/docs/images/feature-notes.png)

### 4. Codex / Claude 额度和英语学习

AI 额度页会把 Codex 与 Claude Code 放在一起，显示最紧张的额度窗口、剩余比例、重置时间和当前使用节奏。这个功能的出发点也很朴素：用 AI 写到一半时，我总想知道今天还能折腾多久。

![Codex 与 Claude Code 额度](https://raw.githubusercontent.com/kuaoaoaoao/CoolRun/main/docs/images/feature-ai.png)

英语学习则内置了分级单词、句子和短文，支持系统语音朗读、收藏、掌握程度、复习进度和连续学习天数。它不是想替代专业背词软件，只是希望我每次打开菜单栏时，能顺手多看一个单词。

### 5. “今天”总览和快捷操作

功能变多后，我也发现逐个页面查看会变得麻烦，所以又做了一个“今天”页面：把系统健康、最近的倒数日或生日、黄金持仓、英语进度和 AI 额度按紧急程度排在一起，点击就能跳到对应模块。

另外也支持 macOS“快捷指令”，可以打开指定模块、刷新金价，以及播放或暂停英语内容。

## 关于隐私和这个项目

我希望这类个人工具尽量本地优先。备忘录、剪切板、生日、倒数日、英语进度、系统趋势、金价记录和持仓数据都保存在自己的 Mac 上；匿名使用统计默认关闭。需要联网的功能，例如金价、节假日、软件更新和 AI 额度，只会在使用对应功能时访问相关服务。

项目源码公开，目前采用 PolyForm Noncommercial 1.0.0 非商业许可。代码里肯定还有不少不成熟的地方，但如果它能给同样在学 macOS 开发、或者也喜欢折腾菜单栏工具的人一点参考，我也会很开心。

## 下载和安装

- 项目地址：[GitHub - CoolRun](https://github.com/kuaoaoaoao/CoolRun)
- 最新版本：[CoolRun v4.0.0](https://github.com/kuaoaoaoao/CoolRun/releases/tag/v4.0.0)
- 系统要求：macOS 15 或更高版本

目前安装包还没有经过 Apple 公证。下载 `CoolRun.dmg` 后拖入“应用程序”；如果第一次启动被 macOS 拦截，可以到“系统设置 → 隐私与安全性”中确认“仍要打开”。介意这一点的话，也可以直接用 Xcode 查看源码后自行构建。

以上就是 CoolRun 的由来。它并不是一个一开始就规划得很完整的产品，更像是我在使用 Mac 的过程中，把一个个真实的小需求慢慢放进了同一个工具里。功能确实有点多，也还有很多可以改进的地方，欢迎大家试用、提 Issue 或直接拍砖。尤其想听听大家对菜单栏交互、Mac 诊断结果是否好理解，以及哪些功能应该继续做减法的意见。
