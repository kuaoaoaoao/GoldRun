coolRun

把金价、Mac 状态和小说阅读收进菜单栏。

实时金价、持仓建议、系统监控、农历生日、txt 阅读和系统语音朗读都在一个轻量悬浮窗里。图钉固定后，它可以像桌面小工具一样停在手边。

金价不只显示一个数字

新版本把实时价格、指标解释、个人成本和风险提示放到一起。对新手来说，它会尽量用“可小额分批”“暂不建议追买”“盈利可分批落袋”这样的普通话讲清楚。

¥/g 实时价格与走势

展示积存金价格，记录本地历史样本，支持折线、K 线和周期切换。

RSI 指标翻译成人话

RSI、MACD、均线、波动率、支撑位和压力位都有新手解释。

POS 个人持仓建议

输入持有克数与买入均价，自动计算成本、市值、浮盈浮亏和分批策略。

小说阅读可以留在悬浮窗里

完整窗口适合沉浸阅读，菜单栏迷你阅读器适合边工作边看一段、听一段。朗读控制与阅读进度共用同一套书库。

  • 导入 txt 后自动解析章节，保存上次阅读位置。
  • 支持书签、主题、字号、行距、滚动阅读和翻页阅读。
  • 语音朗读支持播放、暂停、停止、上一句、下一句和自动跟随。

安装与使用

从 GitHub Releases 下载应用，拖入 Applications 文件夹后启动即可。

下载安装包

进入 Releases 页面，下载最新的 coolRun.dmg 或 coolRun.zip。

安装应用

打开 DMG，将 coolRun.app 拖入 Applications 文件夹。

开始使用

启动后在菜单栏找到金币图标，左键打开悬浮窗，右键打开快捷菜单。

如果 macOS 提示无法验证开发者，可以右键点击 coolRun.app，选择“打开”，再在系统弹窗中确认。若提示文件已损坏，通常是因为应用暂未公证，可参考 README 中的安装说明处理。
