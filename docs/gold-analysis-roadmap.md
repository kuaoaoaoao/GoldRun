# 黄金分析模块成熟化计划

更新时间：2026-07-17

## 目标

把当前黄金分析从"规则型辅助判断"逐步升级为"可解释、可复盘、可自我校准"的个人黄金购买助手。

软件结论始终只作为逻辑分析参考，不构成投资建议。界面需要展示证据、数据来源、历史验证表现和风险提示，让用户自行判断。

## 当前状态

当前黄金模块已经具备以下能力：

- 实时获取浙商积存金价格，并保存本地历史价格。
- 计算 SMA、EMA、RSI、MACD、布林带、波动率、ROC、支撑压力、最大回撤。
- 生成基础买入、卖出、观望信号，并展示原因。
- 识别市场状态：强势上涨、温和上涨、震荡整理、温和下跌、强势下跌。
- 计算 ADX、Hurst、均值回归、短期蒙特卡洛模拟、网格区间、建议仓位。
- 读取美债 10 年期收益率和 Google News RSS 标题，形成宏观新闻分。
- 记录非观望预测，并在约 30 分钟后用真实价格验证。
- 展示新手结论、判断依据、宏观新闻、预测学习和免责声明。
- 根据用户持仓克数、买入均价，给出盈亏和持仓建议。

## 阶段二：自我校准

目标：让历史验证结果反过来影响后续建议。

已完成：
- 当验证样本不足 8 条时，只记录不自动调参。
- 当方向命中率偏低时，自动降低信心和建议仓位。
- 当预测偏乐观时，自动降低买入建议权重。
- 当近期表现较好时，只做轻微积极校准，避免过拟合。
- **新增**：按策略版本、市场状态、预测方向分组统计已实现。

目标：从"当前辅助判断"升级到"可回测、可比较、可解释"的成熟项目。

待补充：

- 回测指标：方向命中率、平均误差、最大回撤、盈亏比、观望占比。
- 参数版本对比：比较不同策略版本在历史数据中的表现。

- 风险预算：根据用户资金、持仓、风险偏好，给出分批计划和最大风险。
- 用户计划：目标仓位、定投预算、止盈/止损提醒、回本线提醒。
- 复盘解释：错误预测自动分类，例如趋势反转、新闻冲击、数据缺失、过度乐观。

## 技术方向

当前阶段优先用 Swift 本地实现，不急着引入 Python 爬虫。

可选技术：

- Swift URLSession：继续用于轻量宏观数据和 RSS 获取。
- 本地 JSON 数据集：继续记录预测和验证结果。
- SQLite：当预测记录、价格历史、新闻记录增长后再引入。
- LLM 摘要：后续可用于新闻事件归因，但必须保留原始证据。
- Python：只在需要复杂离线回测、批量数据处理或多源爬虫时引入。

## 风险原则

- 不输出"必买""稳赚"等确定性文案。
- 所有建议都要展示依据和反方风险。
- 样本不足时明确提示"样本积累中"。
- 数据缺失时明确提示"数据不完整"。
- 历史命中率差时自动保守，而不是继续强推买入。
