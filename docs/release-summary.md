# CoolRun 当前版本更新总结

更新时间：2026-08-01

本文档用于发布前核对当前版本的主要能力、隐私边界和验证结果。

## 一句话介绍

CoolRun 是一个本地优先的原生 macOS 菜单栏工作台：既能查看系统、金价、AI 额度和日历等日常信息，也能排查睡眠耗电、网络连接、System Data 与应用残留。

## 本版重点：Mac 诊断

### 1. 睡眠与耗电

- 分析当前阻止休眠的电源断言和关联进程。
- 汇总最近 24 小时的 Sleep、Wake、Dark Wake 与电量变化。
- 保存有上限的诊断摘要，不保存原始系统日志。

### 2. 网络医生

- 分层检查网卡、默认路由、DNS、Ping、HTTPS 和 VPN。
- 单项失败时继续执行其他检查，并明确显示部分完成状态。
- 不抓包、不保存浏览历史或网络内容。

### 3. System Data 透视

- 只读统计缓存、日志、应用支持、容器、开发文件和设备备份。
- 展示空间热点、扫描进度和无法访问的范围。
- 支持在 Finder 中定位，不在存储分析中直接删除文件。

### 4. 应用残留

- 只展示经过安装状态、路径、年龄和保护规则筛选的高置信度候选。
- 清理前列出目标并二次确认，执行前再次校验。
- 只移入废纸篓；失败时保留原文件，不进行永久删除。

## 已有工作台能力

- 系统与进程监控：CPU、内存、存储、电池、网络、温度、运行时间与进程排行。
- 今天与提醒：生日、倒数日、英语打卡、系统异常与免打扰时段。
- 金价与持仓：实时价格、历史走势、技术指标、策略解释、交易记录与个人盈亏。
- AI 额度：Codex 与 Claude Code 的剩余比例、重置时间和使用节奏。
- 日历与英语：公历农历、节假日、分级学习内容、复习进度与语音。
- 备忘录与剪切板：分组、搜索、固定和本地纯文本历史。

## 用户使用路径

1. 启动 CoolRun，在菜单栏查看选中的状态信息。
2. 左键打开悬浮窗，使用顶部导航切换模块。
3. 进入“诊断”或按 `Command + 8`，选择睡眠、网络、存储或残留。
4. 睡眠、网络与存储检查均按需运行，不会在后台持续扫描。
5. 残留清理必须手动选择并确认，文件只会移入废纸篓。

## 隐私与安全边界

- 诊断结果默认只保存在本机，原始电源日志、浏览历史和文件内容不会进入历史记录。
- System Data 扫描是只读操作，访问受保护目录失败时会显示为扫描不完整。
- 残留扫描不触碰系统目录、Group Containers 或无法确认归属的 Application Support 文件夹。
- 匿名统计默认关闭，个人内容、文件路径、诊断正文和账号凭据不进入统计。
- 金价分析和持仓建议仅用于信息展示与个人记录，不构成投资建议。
