# coolRun 本次功能更新总结

本文档用于发布前梳理本次代码改动和面向用户的功能说明。

## 一句话介绍

coolRun 从一个“菜单栏金价 + Mac 状态监控”工具，扩展成了一个轻量菜单栏工作台：实时金价、金价分析、个人持仓建议、系统监控、日历生日、小说阅读和语音朗读都可以在菜单栏悬浮窗中使用。

## 新增与增强功能

### 1. 金价分析模块

- 接入历史金价记录，刷新成功后会写入本地价格序列。
- 新增金价分析页面，包含当前价格、涨跌、24 小时走势、迷你 K 线和周期切换。
- 新增技术指标：RSI、MACD、SMA20、波动率、支撑位、压力位。
- 新增交易信号引擎，输出偏多、偏空、观望，以及入场、止损、止盈参考。
- 新增术语解释，把 RSI、MACD、均值回归、网格、建议仓位等专业词写成新手能理解的说明。

### 2. 高级策略模块

- 市场状态识别：区分强势上涨、温和上涨、震荡整理、温和下跌、强势下跌。
- 均值回归分析：判断价格是否明显偏离近期均值。
- 蒙特卡洛模拟：基于历史波动估算短期价格区间和上涨概率。
- 网格策略参考：给出震荡行情下的上下沿、格数和间距。
- 风险仓位建议：根据行情、波动和信号强度给出更保守的参与比例。
- 新手结论：用“可小额分批观察”“观望为主”“暂不建议买入”“不建议追买”等普通语言表达。

### 3. 个人持仓建议

- 新增“我的黄金”卡片。
- 用户可输入当前持有克数和买入均价。
- 自动计算成本、市值、浮盈/浮亏、收益率和回本线。
- 亏损时提示是否适合分批补仓、如何降低均价、什么时候先观望。
- 盈利时提示继续持有、设置保本线或部分卖出锁定利润。
- 输入会通过 `AppStorage` 保存在本机。

### 4. 小说阅读模块

- 新增小说书架，支持导入 txt 文件。
- 自动解析章节、保存书籍信息、阅读进度和书签。
- 新增完整小说阅读器，支持目录、书签、滚动阅读、翻页阅读。
- 新增阅读设置：字号、行距、主题和阅读模式。
- 支持明亮、暖色、复古、暗夜、水墨主题。

### 5. 语音朗读

- 使用 macOS 系统 `AVSpeechSynthesizer` 朗读小说。
- 支持播放、暂停、继续、停止、上一句、下一句。
- 支持语速、音调、音量和语音选择。
- 支持朗读时自动滚动到当前段落。
- 支持章节结束后自动继续下一章。

### 6. 菜单栏悬浮阅读

- 菜单栏悬浮窗新增“小说”入口。
- 新增菜单栏迷你小说阅读器，可选择书籍、导入 txt、切换章节、切换段落。
- 迷你阅读器内置朗读控制，可在悬浮窗中播放、暂停、停止、前后句跳转。
- 新增图钉固定功能，固定后悬浮窗不会因为点击其他应用而自动关闭。

### 7. UI 与布局优化

- 菜单栏悬浮窗宽度从窄版增加到更适合四个入口和小说内容的尺寸。
- 顶部入口改成更紧凑的四列布局：监控、金价、日历、小说。
- 为顶部按钮添加压缩策略，减少文字被挤压或遮挡。
- 小说迷你阅读器采用固定高度正文区和紧凑按钮，避免语音控制遮挡正文。
- 金价持仓卡片保持窄面板适配，输入框、盈亏摘要和建议文案分区展示。

## 用户使用路径

1. 启动 coolRun 后，在菜单栏看到金币图标和金价/日期。
2. 左键点击图标打开悬浮窗。
3. 顶部切换监控、金价、日历、小说。
4. 点击图钉可固定悬浮窗。
5. 在金价页输入持有克数和买入均价，查看个人持仓建议。
6. 在小说页导入 txt，固定悬浮窗后可以边工作边阅读或听朗读。

## 注意事项

- 金价数据来自第三方接口，稳定性和准确性取决于接口服务方。
- 金价分析和持仓建议仅供信息参考，不构成投资建议。
- 小说文件、阅读进度、书签和个人持仓输入都保存在本机。
- 当前构建仍存在项目原有的 Swift 6 并发捕获 warning，以及 app sandbox entitlement warning；不影响本次功能编译通过。
