# GoldRun 本次功能更新总结

本文档用于发布前梳理本次代码改动和面向用户的功能说明。

## 一句话介绍

GoldRun 从一个“菜单栏金价 + Mac 状态监控”工具，扩展成了一个轻量菜单栏工作台：实时金价、金价分析、个人持仓建议、系统监控、日历生日、分组备忘录、剪切板历史、英语学习和 AI 额度都可以在菜单栏悬浮窗中使用。

## 新增与增强功能

### 1. 金价分析模块

- 接入历史金价记录，刷新成功后会写入本地价格序列。
- 新增金价分析页面，包含当前价格、涨跌、24 小时走势、迷你 K 线和周期切换。
- 新增技术指标：RSI、MACD、SMA20、波动率、支撑位、压力位。
- 新增交易信号引擎，输出偏多、偏空、观望，以及入场、止损、止盈参考。
- 新增术语解释，把 RSI、MACD、均值回归、网格、建议仓位等专业词写成新手能理解的说明。

### 2. 高级策略模块

- 市场状态识别：区分强势上涨、温和上涨、震荡整理、温和下跌、强势下跌。
- 均值回归分析：判断价格是否明显偏离近期均值。
- 蒙特卡洛模拟：基于历史波动估算短期价格区间和上涨概率。
- 网格策略参考：给出震荡行情下的上下沿、格数和间距。
- 风险仓位建议：根据行情、波动和信号强度给出更保守的参与比例。
- 新手结论：用“可小额分批观察”“观望为主”“暂不建议买入”“不建议追买”等普通语言表达。

### 3. 个人持仓建议

- 新增“我的黄金”卡片。
- 用户可输入当前持有克数和买入均价。
- 自动计算成本、市值、浮盈/浮亏、收益率和回本线。
- 亏损时提示是否适合分批补仓、如何降低均价、什么时候先观望。
- 盈利时提示继续持有、设置保本线或部分卖出锁定利润。
- 输入会通过 `AppStorage` 保存在本机。

### 4. 分组备忘录与剪切板历史

- 备忘录支持标题、正文、自定义分组、搜索、固定、移动与安全删除。
- 标题留空时从正文第一行自动生成；删除分组时，其中的备忘自动移入“未分组”。
- 剪切板历史仅采集应用启动后新复制的纯文本，重复内容会刷新到顶部。
- 支持搜索、固定、一键重新复制、暂停、逐条删除和确认后清空，最多保留 200 条。
- 两类个人内容均保存于本机 Application Support，不进入匿名统计或网络请求。

### 5. UI 与布局优化

- 菜单栏悬浮窗宽度从窄版增加到更适合多模块内容的尺寸。
- 顶部入口改成更紧凑的模块导航布局。
- 为顶部按钮添加压缩策略，减少文字被挤压或遮挡。
- 金价持仓卡片保持窄面板适配，输入框、盈亏摘要和建议文案分区展示。

## 用户使用路径

1. 启动 GoldRun 后，在菜单栏看到金币图标和金价/日期。
2. 左键点击图标打开悬浮窗。
3. 顶部切换今天、监控、金价、日历、英语、AI 额度、备忘录和剪切板。
4. 点击图钉可固定悬浮窗。
5. 在金价页输入持有克数和买入均价，查看个人持仓建议。

## 注意事项

- 金价数据来自第三方接口，稳定性和准确性取决于接口服务方。
- 金价分析和持仓建议仅供信息参考，不构成投资建议。
- 个人持仓输入保存在本机。
- 备忘录与剪切板内容保存在本机；剪切板记录可随时暂停或清空。
- 发布前已通过完整单元测试、界面渲染测试、Xcode 静态分析和未签名 macOS 构建。
